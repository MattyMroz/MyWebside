# Sarajewo · przewodnik mobilny

Osobna, statyczna podstrona podróżna. Nie zmienia istniejącej strony głównej repozytorium.

## Plan realizacji

1. Zweryfikować adresy, ceny i godziny w publicznych źródłach, zamiast przepisywać niepotwierdzone informacje z rozmowy.
2. Ułożyć plan 6–11 września 2026 z uwzględnieniem agendy szkoły letniej i piątkowego powrotu.
3. Przygotować mobilny HTML z jasnym i ciemnym motywem, mapą z gwiazdkami, nawigacją Google Maps i kalkulatorem BAM/PLN.
4. Dodać praktyczne informacje: jedzenie, transport, płatności, internet, bezpieczeństwo i wariant deszczowy.
5. Sprawdzić interakcje oraz publikację w GitHub Pages.

## Prywatność

Bez nazwisk uczestników, treści maili, skanów biletów, numerów rezerwacji, kodów QR, numerów telefonu użytkowników i identyfikatorów kart SIM. Strona jest publiczna; daty i punkty planu podróży są widoczne. `noindex` ogranicza indeksowanie, ale nie zabezpiecza dostępu.

## Dane

Informacje weryfikowane 6 września 2026. Źródła i ograniczenia są podane na stronie. Ceny restauracji z dostawy mogą różnić się od cen na miejscu. Kurs jest orientacyjny, a nie kursem rozliczeniowym karty. Odległości nie zastępują nawigacji.
